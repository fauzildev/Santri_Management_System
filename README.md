# Santri_Management_System
A simple Python CLI project to manage santri data using JSON storage
A simple Python-based command-line application to manage santri (student) data.

## Features
- Add santri data (name and room)
- View all santri
- Search santri
- Delete santri
- Persistent data storage using JSON

## Technologies Used
- Python
- JSON
